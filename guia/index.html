Publica el Informe BYR en internet

La guía más fácil del mundo para llevar tu depuración de inventario desde la carpeta de Descargas hasta problemacero.com/informe-inv-byr. GitHub, Vercel y Supabase en 6 pasitos.

⏱️ Lectura: 8 minutos 📱 Apta para móvil 🖨️ Apta para exportar en PDF ✅ 6 Pasos Visuales
🎯 Meta final: https://problemacero.com/informe-inv-byr
Paso 1 • La LlavePaso 1 de 6

Conecta la llave mágica de GitHub

Darle permiso a tu computador para guardar cosas en tu cuenta de GitHub.

🧸 En palabras súper sencillas GitHub es como un baúl gigante en internet donde viven los juguetes de los programadores. Para abrir el baúl necesitas una llave mágica. Este comando te da un numerito secreto: lo copias, lo pegas en la página de GitHub y ¡pum!, tu computador queda autorizado.

Lugar: Terminal PowerShell • En tu computador

DÓNDE TOCAR: gh auth login
Instrucciones Rápidas:
  1. Abre PowerShell: tecla Windows, escribe powershell, Enter.
  2. Copia y pega gh auth login y presiona Enter.
  3. Escoge con las flechitas: GitHub.com → HTTPS → Login with a web browser.
  4. Aparece un código de 8 letras (ejemplo: AB12-CD34). Cópialo.
  5. Presiona Enter: se abre tu navegador. Pega el código y toca Authorize github.
  6. Si te pide usuario y contraseña de GitHub, escríbelos y sigue. Verás un check verde ✓.
Paso 2 • El BaúlPaso 2 de 6

Crea el baúl y sube la maleta completa

Crear el repositorio informe-inv-byr y subir los 6 archivos con un solo hechizo.

🧸 En palabras súper sencillas Tu app es una maleta lista (yo ya la empagué). Ahora creamos un baúl nuevo con el nombre exacto informe-inv-byr y el hechizo --push sube todo adentro de una sola vez.

Lugar: Terminal PowerShell • Carpeta del proyecto

DÓNDE TOCAR: cd C:\Users\User\Downloads\byr-inventario git branch -M main gh repo create informe-inv-byr --public --source=. --push
Instrucciones Rápidas:
  1. En la terminal entra a la carpeta: cd C:\Users\User\Downloads\byr-inventario
  2. Ponle el nombre de rama moderno: git branch -M main
  3. Pega el hechizo: gh repo create informe-inv-byr --public --source=. --push y Enter.
  4. Espera el mensaje ✓ Created repository ... y ✓ Uploaded.
  5. Abre github.com/TU-USUARIO/informe-inv-byr: verás tus 6 archivos brillando.
✅ Si el navegador muestra los archivos index.html, app.js y styles.css, el baúl quedó perfecto.
Paso 3 • El CohetePaso 3 de 6

Vercel enciende el cohete 🚀

Importar el repositorio en Vercel para que la app quede viva en internet.

🧸 En palabras súper sencillas Vercel es una fábrica de cohetes. Le entregas tu baúl de GitHub y en menos de un minuto te devuelve una página web viva, con una dirección temporal: informe-inv-byr.vercel.app. La dirección bonita viene en el paso siguiente.

Lugar: vercel.com/new • En tu navegador

DÓNDE TOCAR: ABRIR VERCEL.COM/NEW 👆
Instrucciones Rápidas:
  1. Entra a vercel.com con la misma cuenta con la que manejas problemacero.com (botón "Continue with GitHub" es lo más fácil).
  2. Toca Add New… → Project y busca informe-inv-byr → Import.
  3. En Framework Preset escoge Other. Deja vacíos Build Command y Output Directory.
  4. Toca el botón azul Deploy y espera el confeti 🎉 (menos de 1 minuto).
  5. Copia la dirección que te dio (ejemplo: informe-inv-byr.vercel.app). ¡Ya funciona!
✅ Prueba la dirección temporal en tu celular. Si abre la app con el título «Resumen del corte», el cohete voló bien.
Paso 4 • La Dirección BonitaPaso 4 de 6

La puerta secreta: problemacero.com/informe-inv-byr

Hacer que tu dominio principal abra esta app en su ruta propia.

🧸 En palabras súper sencillas problemacero.com es tu casa y el informe vive en una casita nueva (informe-inv-byr.vercel.app). Vamos a instalar una puerta secreta: cuando alguien toca tu-casa/informe-inv-byr, un mayordomo invisible lo lleva volando a la casita. El mayordomo se llama rewrite.

Lugar: Repositorio problemacero.com • Archivo vercel.json o next.config

DÓNDE TOCAR: Carpeta raíz del proyecto principal en GitHub

Pega esto en vercel.json del proyecto principal (si no existe, créalo):

{
  "rewrites": [
    { "source": "/informe-inv-byr", "destination": "https://informe-inv-byr.vercel.app/" },
    { "source": "/informe-inv-byr/:path*", "destination": "https://informe-inv-byr.vercel.app/:path*" }
  ]
}
Instrucciones Rápidas:
  1. Abre el repositorio de problemacero.com en GitHub (donde vive tu web principal).
  2. Si ya existe vercel.json, agrega solo la lista "rewrites" dentro de las llaves. Si tu proyecto usa next.config.js, pon las mismas dos reglas en su sección rewrites().
  3. Guarda con Commit changes y espera el nuevo deploy (1–2 minutos).
  4. Abre https://problemacero.com/informe-inv-byr 🎉
⚠️ Si aún no hiciste el paso 4, mientras tanto comparte la dirección temporal del paso 3: funciona exactamente igual.
Paso 5 • Las Llaves de SupabasePaso 5 de 6

El cuaderno de la nube para todo el equipo

Registrar la nueva dirección en Supabase y conectar el historial compartido.

🧸 En palabras súper sencillas Supabase es el cuaderno mágico donde quedan guardados los cortes de cada semana para todo el equipo. Hay que decirle qué puertas tienen permiso de entrada (tu dirección bonita y la temporal), y luego pegar su llave pública dentro de la app.

Lugar: supabase.com/dashboard • Tu proyecto BYR

DÓNDE TOCAR: Authentication → URL Configuration
Instrucciones Rápidas:
  1. En Supabase entra a Authentication → URL Configuration.
  2. Site URL: https://problemacero.com/informe-inv-byr
  3. Redirect URLs: agrega https://problemacero.com/informe-inv-byr/** y https://informe-inv-byr.vercel.app/**.
  4. Copia Project URL y la anon public key (Settings → API).
  5. En la app: Ajustes → Conexión Supabase, pega los dos valores y toca Guardar y conectar.
  6. En Historial, crea tu cuenta con tu correo. Cada usuario solo ve sus propios cortes.
✅ Sin Supabase la app igual funciona (modo local, se guarda solo en tu navegador). Con Supabase, todo el equipo comparte el historial.
Paso 6 • La Prueba FinalPaso 6 de 6

Guarda tu primer corte real 🏁

Cargar los archivos de esta semana y verificar los números mágicos.

🧸 En palabras súper sencillas Es como la primera vuelta en bicicleta sin rueditas. Si ves los números correctos, todo el circuito quedó perfecto: GitHub → Vercel → tu dominio → Supabase.

Lugar: La app publicada • Cualquier dispositivo

DÓNDE TOCAR: ABRIR EL INFORME 👆
Instrucciones Rápidas:
  1. Abre https://problemacero.com/informe-inv-byr.
  2. Toca Cargar archivos: PDF del sistema + Excel del conteo físico.
  3. Confirma la fecha de corte (ejemplo: 15/11/2026).
  4. Verifica los números: 613 a eliminar · 141 a incluir · 15 excluidas.
  5. Toca Guardar corte y márcalo en el Historial. ¡Publicación completa!

✅ Checklist final

  • Repo informe-inv-byr visible en GitHub.
  • Proyecto en Vercel con Framework Preset: Other.
  • Ruta bonita abriendo la app.
  • Redirect URLs de Supabase configuradas.
  • Primer corte guardado en el Historial.

🩹 Si algo falla

  • 404 en la ruta bonita: el rewrite falta o el deploy del sitio principal no ha terminado. Espera 2 minutos.
  • Vercel no encuentra el repo: en vercel.com → Settings → GitHub, dale acceso al repo nuevo.
  • El PDF no carga: debe ser el PDF del sistema con texto (no escaneado como foto).
  • Números distintos: revisa la fecha de corte en «Archivos del corte».
